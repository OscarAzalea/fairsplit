## 🎮 What is FairSplit?
**FairSplit** is a fintech web application engineered for collaborative creative teams (such as indie game studios and music co-ops) operating under shared revenue agreements.

In collaborative projects like indie game **"Project Aurora"**, equity disputes, spreadsheet calculation drift, unrecorded retroactive split shifts, and opaque payout lump sums frequently jeopardize release schedules and trust.

FairSplit resolves this through 4 foundational pillars:
1. **Deterministic Fintech Math in Integer Cents**: Zero floating-point errors (`0.1 + 0.2` drift eliminated). Hamilton-Hare Largest Remainder Method ensures exact penny distribution where `sum(shares) === netInflow` always.
2. **Agreement Studio**: 4-member rev-share (*Dev 40%, Artist 30%, Writer 20%, Composer 10%*). Interactive auto-balancing dials + Gemini-powered **Socratic AI Negotiation Drawer** (structured trade-off synthesis) + multi-party cryptographic ratification.
3. **Trust Ledger**: Append-only SHA-256 hash-chained epochs (`v1.0` &rarr; `v2.0`). Every customer inflow captured via PayPal is immutably stamped with the active epoch hash. Includes a live **Cryptographic Integrity Verifier** and a **"Simulate Malicious Tamper"** test tool.
4. **Payments Hub**:
   - **Inflows**: PayPal Sandbox Orders API checkout simulator (`/v2/checkout/orders` with intent: `CAPTURE`) calculating standard commercial fees (2.99% + $0.49).
   - **Outflows**: PayPal Sandbox Payouts API batch distribution console (`/v1/payments/payouts`) with per-item idempotency tracking (`sender_item_id`, `payout_item_id`, `SUCCESS`/`PENDING`/`FAILED`).
5. **"Explain My Balance" AI Auditor**: Collaborators can click any balance card to receive a 100% mathematically faithful, plain-English breakdown of every dollar earned, fee deducted, and cryptographic epoch link.

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm run start
```

## 🧪 Hackathon Judging & Interactive Walkthrough

1. **Agreement Studio**:
   - Adjust any member's slider dial (e.g. raise Composer from 10% to 15%). Notice how the dials automatically rebalance the unlocked team members while preserving the exact 10,000 basis points (100.0%) total.
   - Click **"Socratic AI Mediator"** to open the Gemini negotiation drawer. Review the trade-off synthesis, Socratic probing questions, and consensus score.
   - Click **"Propose New Epoch"** to start the 4-party ratification flow. Sign individually or click **"Fast-Ratify All (Demo)"** to lock and activate Epoch `v2.0`!

2. **Trust Ledger (SHA-256)**:
   - Observe how the hash chain updates with block `v2.0` linked to `v1.0.hash`.
   - Click **"Verify Chain"** in the top navigation to watch the client-side SHA-256 validator verify all blocks.
   - Click **"Simulate Malicious Tamper"** to witness the cryptographic alarm detect tampered split data immediately!

3. **Payments Hub (Inflows & Outflows)**:
   - In the Inflows panel, select **"Steam Batch ($2,500.00)"** or enter a custom amount.
   - Review the deterministic fee calculation ($75.24) and exact penny allocation table.
   - Click **"Simulate PayPal Checkout & Capture"** to execute the PayPal Orders API and anchor the revenue event to the active epoch.
   - In the Outflows panel, inspect the raw JSON payload conforming to PayPal's `/v1/payments/payouts` API specification, then click **"Disburse Batch via PayPal Payouts"** to disburse funds with idempotent tracking.

4. **Collaborator Balances & AI Audit**:
   - Go to **Collaborator Balances** to see updated real-time balances in cents and dollars.
   - Click **"Explain My Balance (AI)"** on any member (e.g. Alex the Dev or Lyra the Composer) to review the transparent, plain-English ledger audit generated by Gemini.
